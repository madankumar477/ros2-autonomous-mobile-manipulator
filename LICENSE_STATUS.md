- `edubot_me6_description/package.xml` declares MIT.
- `edubot_me6_moveit/package.xml` declares BSD and attributes the generated package to DOBOT.
- `edubot_description`, `edubot_controller`, and `edubot_bringup` have `TODO: License declaration` in their original package manifests. Those fields have intentionally not been changed without verified ownership/license details.

- Selected AWS RoboMaker warehouse world assets are MIT-0; see `licenses/AWS-RoboMaker-MIT-0.txt`.

No repository-wide license is asserted. Public visibility on GitHub is not itself a license grant. Confirm and add a suitable project-wide license only after verifying the rights for every included package and third-party asset.
